## 🛠 Projects

**Ice Flow**

The project involves building an air-cooling system using PWM speed control with Cooler Master fans, achieved through register configuration and interrupt handling for software activation, where the system was configured to operate at a 50% duty cycle.

The electronic circuit diagram used is composed of:
❖ PIC18F4550 microcontroller.
❖ 1N4004 rectifier diode.
❖ Pushbutton (to turn the fans on or off).
❖ 5V relay.
❖ Resistors.
❖ 2N2222 transistor.
❖ 12V, 10A switching power supply.
❖ 2 Master coolers.

Features:
- Register configuration.
- Interrupt handling.
- RPM coding with C.
- Use of an Alteri development board.
- Development environment used: MPLAB X IDE.
- Circuit prototyping tool: Proteus 8 Professional.

Technical specifications of the board:
★The operating voltage is 5V.
★PIC18F4550 microcontroller.
★It has 35 digital pins and 13 analog pins.
★The program memory is 32 KB.
★The EEPROM memory has 256 bytes of storage.
★The maximum speed is 48MHz.
★It has a voltage regulator for connecting an external 9V-12V power supply.
★It has connections for various peripherals (USB, SPI, I2C, UART, PWM, etc.).
